# Python Social Network

Simulação de uma rede social desenvolvida em **Python** utilizando interface de terminal. O projeto foi criado para praticar organização modular do código, manipulação de estruturas de dados e validação de operações entre usuários.

## Funcionalidades

- Cadastro de usuários
- Remoção de usuários
- Criação de amizades bidirecionais
- Remoção de amizades
- Listagem de amigos de um usuário
- Listagem de todos os perfis cadastrados
- Encerramento do sistema com limpeza dos dados em memória

## Tecnologias

- Python 3
- Estruturas de dados (`list` e `dict`)
- Programação modular

## Estrutura do projeto

```text
python-social-network/
│
├── main.py
├── dados.py
├── a_adicionar_usuario.py
├── b_remover_usuario.py
├── c_criar_amizade.py
├── d_remover_amizade.py
├── e_listar_amizades.py
├── f_listar_perfis.py
└── g_sair.py
```

## Como executar

1. Clone o repositório.

```bash
git clone https://github.com/SEU-USUARIO/python-social-network.git
```

2. Acesse a pasta do projeto.

```bash
cd python-social-network
```

3. Execute o programa.

```bash
python main.py
```
